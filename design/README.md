# Folder design

Referensi visual dari Google Stitch, disimpan di `stitch/`:

| Folder | Halaman |
|---|---|
| `ngesrep_beranda` | Beranda |
| `ngesrep_detail_resep_tahu_gimbal` | Detail Resep |
| `ngesrep_tips_dapur` | Tips Dapur |
| `ngesrep_detail_tips_sayur_awet` | Detail Tips |
| `ngesrep_resep_favorit` | Favorit |
| `ngesrep_profil_about` | Profil |

Folder `logo_ngesrep`, `logo_full.png`, dan `app_icon_pwa_512x512_ngesrep` berisi aset merek.
`warm_culinary_modern/DESIGN.md` berisi catatan desain.

File di sini hanya referensi, tidak dipakai aplikasi. Token warna dan ukuran sudah disalin ke
`pwa/tailwind.config.js`, dan aset merek sudah dipakai di `pwa/images/logo-full.png` dan
`pwa/icons/`.
